Bot Mensajería — Minerva Systems

Bot Mensajería es un servicio operado por Minerva Systems que permite a negocios responder automáticamente a sus clientes por WhatsApp, Instagram y Facebook Messenger mediante inteligencia artificial. Esta página describe qué datos procesamos y cómo los usamos.

Qué datos procesamos

Para prestar el servicio, procesamos:

  • El número de teléfono de WhatsApp (o identificador de Instagram/Facebook) de quien escribe al negocio.
  • El contenido de los mensajes intercambiados entre el cliente final y el negocio.
  • Información del catálogo y pedidos del negocio, usada para responder consultas.

Para qué los usamos

Estos datos se usan exclusivamente para generar respuestas automáticas relevantes (consultar stock, tomar pedidos, derivar a una persona cuando corresponde) y para que el negocio pueda revisar el historial de conversaciones con sus propios clientes.

Con quién se comparten

Los mensajes se procesan a través de la API de Meta (WhatsApp Business Platform / Instagram / Messenger) para el envío y la recepción, y a través de la API de Anthropic (Claude) para generar las respuestas. No vendemos ni compartimos estos datos con terceros para fines publicitarios.

Dónde se almacenan

El historial de conversaciones y los datos del negocio se almacenan en una base de datos Azure SQL con acceso restringido, usada únicamente para operar el servicio.
